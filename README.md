# Apex Tech

Sitio web de **Apex Tech**, una tienda ficticia de laptops de alto rendimiento. Proyecto académico de la Universidad de Cuenca (UCUENCA TEC) hecho en pareja con HTML, CSS y JavaScript, publicado con GitHub Pages.

🔗 Sitio publicado: `https://franklincarrion-ayzax.github.io/Apex/
## Páginas
| Archivo | Contenido |
|---|---|
| `index.html` | Inicio: presentación de la tienda |
| `nosotros.html` | Información, misión, visión y equipo |
| `productos.html` | Catálogo de laptops con imágenes y video |
| `contactos.html` | Correo, teléfono, redes sociales y mapa |

## Estructura
```
├── index.html
├── nosotros.html
├── productos.html
├── contactos.html
├── css/styles.css
├── js/main.js
├── img/
├── video/
└── README.md
```

- Rama `main` = rama publicada.
- Cada integrante trabaja en su propia rama (`feature/inicio-nosotros`, `feature/productos-contactos`) y la integra con un Pull Request.
